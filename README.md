# zackaryfick.com

My personal portfolio website, built from scratch with vanilla HTML, CSS, and JavaScript. Hosted on GitHub Pages at [zackaryfick.com](https://zackaryfick.com).

---

## About

A single-page portfolio site I built to showcase my projects, work experience, and extracurriculars while learning web development fundamentals. No frameworks, no libraries — just plain HTML, CSS, and JavaScript.

---

## Features

- **Smooth section navigation** — sticky nav bar with active link highlighting via the Intersection Observer API
- **About, Work, Projects, and Extracurriculars sections** — a full snapshot of my background
- **Responsive layout** — readable on both desktop and mobile
- **Custom Domain deployed on GitHub Pages** — zero cost

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Structure | HTML5 |
| Styling | CSS3 |
| Interactivity | Vanilla JavaScript |
| Hosting | GitHub Pages |
